# AI 浪漫代码

用 AI 写的网页小礼物合集，下载就能用，改个名字就能送人。

| 礼物 | 文件 | 内容 |
| --- | --- | --- |
| 生日限定卡包 | `birthday-surprise.html` | 爱心弹窗开场 → 撕开卡包 → 翻 3 张卡 → 隐藏款 → 吹蜡烛 |

## 怎么领

1. 点上面的 `birthday-surprise.html`，再点右上角的下载按钮（↓ Download raw file）。
2. 下载好后双击，用浏览器（Chrome、Edge、Safari 都行）打开。
3. 点「轻触开启惊喜」开始；进到卡包后沿虚线撕开，点卡片翻开。

一个文件就是全部，不用装任何东西。

## 换成 TA 的名字

1. 撕开卡包后，点右上角的笔图标，填 TA 的名字、你的署名和想说的话。
2. 点「生成专属文件」，会下载一个 `birthday-gift.html`，名字已经写在里面了。
3. 把这个新文件发给 TA，TA 双击打开就是专属于 TA 的版本。

## 小提示

- 横屏（电脑、平板或手机横过来）效果最好。
- 地址栏网址最后加 `?auto`，会全程自动播放。
