# AI 浪漫代码

用 AI 写的小网页礼物合集，每个文件夹是一份，打开就能玩。

| 礼物 | 在线玩 | 说明 |
| --- | --- | --- |
| 生日限定卡包 | `birthday/` | 爱心弹窗开场 → 撕开卡包 → 翻 3 张卡 → 隐藏款 → 吹蜡烛 |

## 怎么用

- **直接玩**：打开网站里对应的文件夹，比如 `.../birthday/`。
- **换成 TA 的名字**：网址后面加 `?name=小美`；卡包右上角的笔图标也能改。
- **自动演示**：网址后面加 `?auto`，全程自动播放。
- **下载到自己电脑**：点仓库右上角绿色的 Code → Download ZIP，解压后把整个 `birthday` 文件夹一起保留，用浏览器打开里面的 `index.html`。

横屏（电脑、平板或手机横过来）效果最好。
